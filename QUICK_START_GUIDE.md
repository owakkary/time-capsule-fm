# Quick Start Guide - Time Capsule FM

## 🚀 Getting Started (30 minutes)

### Step 1: Install Dependencies (5 min)
```bash
cd time-capsule-fm
npm install
npm install lucide-react tailwindcss @tailwindcss/forms postcss autoprefixer
npx tailwindcss init -p
```

### Step 2: Set Up Environment Variables (5 min)
```bash
cp .env.example .env.local
# Then fill in all the API keys in .env.local
```

### Step 3: Copy Starter Files (5 min)

Copy these files from the starter pack to your project:

1. **Replace `tailwind.config.js`** with the new one (has time period colors)
2. **Create `app/globals.css`** (Tailwind styles)
3. **Replace `app/layout.tsx`** with the new one
4. **Create `app/login/page.tsx`** (login page)
5. **Create `app/components/` folder** and add:
   - `EraSelector.tsx`
   - `DurationSelector.tsx`
   - `EpisodeGenerator.tsx`
6. **Create `app/dashboard/page.tsx`**

### Step 4: Update Package.json (2 min)

Add these to your `dependencies`:
```json
{
  "lucide-react": "^0.294.0",
  "tailwindcss": "^3.4.0",
  "@tailwindcss/forms": "^0.5.7"
}
```

### Step 5: Test It (5 min)
```bash
npm run dev
```

Visit http://localhost:3000/login

## 🔧 Troubleshooting

### "Module not found: @/types"
- Make sure you have the `types/index.ts` file in your project
- Check your `tsconfig.json` has the `@/*` path mapping

### "Firebase not configured"
- Check `.env.local` has all Firebase variables
- Make sure you've set up Firebase project
- Verify `lib/firebase.ts` exists

### Tailwind styles not working
- Make sure you ran `npx tailwindcss init -p`
- Check `app/globals.css` is imported in `app/layout.tsx`
- Restart dev server: `npm run dev`

### API routes returning 401
- Check Firebase Admin credentials in `.env.local`
- Make sure `lib/firebase-admin.ts` exists
- Verify auth token is being sent in requests

## 💡 Tips for Success

1. **Start Simple**: Get login working first, then dashboard, then generator
2. **Test Each Step**: Don't move to the next component until the current one works
3. **Use Console**: Check browser console for errors
4. **Read Error Messages**: They're usually helpful!
5. **One File at a Time**: Don't try to copy everything at once
